# Flappy Bird in Bevy

The web version of the game can be played here: [Github Pages](https://BigB132.github.io/first_rust_game/)

A simple flappy bird game made in Bevy. This is actually my first bevy/rust project, as i've just learnt the basics recently.
This is my submission for the terra hackclub event (Prep Week #2).


![Flappy Bird Gameplay](./img.gif)

## Building

Build the project by using
```
cargo build
```

Then run it using
```
cargo run
```

or build the executable using
```
cargo build --release
```
